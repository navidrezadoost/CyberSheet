## Mixed-operation exact-state design

The current operation set is **six operation kinds**: five cell writes and `setRowHeight`. Adding the candidate would make **seven kinds**. A complete mixed test must stage all five cell operations, row height, and column width in one transaction, with interleaved operations and at least two Worksheets. Both Journal and Snapshot strategies must reach the same observable final and restored state.

For a column whose initial map state is absent, first-touch records absence even though `getColumnWidth()` returns 80. For another column, seed an explicit 80 entry and record `{present:true,widthPx:80}`. Write each target more than once. On rollback, compare explicit snapshot entries as well as getter values; the absent entry must remain absent and explicit 80 must remain present. For multiple Worksheets, rollback restores all participating width maps, row-height maps, cells, and graph state before discarding batches. Event traces must be empty on rollback and equal in order/frequency after success.

This is an operation-specific design proposal. It does not claim arbitrary Worksheet state is transactional or alter the production Journal default.
