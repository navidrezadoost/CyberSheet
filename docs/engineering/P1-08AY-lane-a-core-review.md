## Method and ownership boundary

Matched each selected `(record_type, record_key, path)` to its current source line, traced the command's raw `Worksheet` caller/receiver, and checked prior occurrence-specific sections in [CS-002D4-R1 implementation reconciliation](CS-002D4-R1-implementation-reconciliation.md). Reused J.06 exact-key evidence for `ClearCellsCommand`/`SetHyperlinkCommand`, T.06's exact flow-key evidence for the two ClearCells transaction callbacks, and N.06/O.06 exact-key evidence for `WorksheetCommands`. Direct test observations below are the previously reported results, not new runs.

The three command families accept a raw `Worksheet`; `Workbook.create()` adopts sheets and publishes `WorkbookSheetView` handles ([workbook.ts:119–147](../../packages/core/src/workbook.ts:119)). The worksheet owner guard rejects raw mutator entrypoints, including the selected ClearCells calls, hyperlink calls, snapshot application, structural operations, styles, and drawing operations ([worksheet.ts:189–207, 408–409, 3770–3781](../../packages/core/src/worksheet.ts:189)). Existing command tests use standalone `Worksheet` instances. They establish those standalone behaviors, not an owner-backed command path. `owner-blocked` marks that missing Workbook-owned route; `evidence-insufficient` marks static-only records with no runtime behavior to infer.

**Source mapping note:** the prior J.06 row for key `317aaad98ce62bb63648` describes line 75 as `clearCellFormula()`. The frozen semantic register and current source both identify line 75 as `setCellFormula()`; the current test's formula snapshot follows that branch. This review uses the exact selected key/path/line and current expression, and treats the older method label as a reporting mismatch.

## Limits and candidate next evidence

- Results are scoped to the exact occurrences above. Nearby tests do not establish an unlisted command or callsite. Existing reported focused results are cited; no suite was rerun for this review.
- The raw Worksheet guard makes the owner boundary visible, and `workbook-owned-escape.test.ts:20–30` verifies adopted raw cell/style mutations reject before writing. The selected ClearCells and hyperlink commands have no supported `TransactionSheet`/`WorkbookSheetView` entrypoint. Structural/style/drawing command operations are later R5 slices; ClearCells' journal-backed cell-content calls depend on the separately gated R2 path.
- Candidate next evidence, after the relevant owner scope is authorized: exercise ClearCells only through a supported journal-backed transaction capability, checking commit/rollback and undo/redo; add separate approved owner routes and focused tests for hyperlink, structural, style, and drawing commands. Keep standalone fixtures as their own evidence. Static import/type keys need an explicit type-boundary/compiler assertion only if a public type claim is intended; runtime behavior cannot prove those occurrences.
