## Coverage conclusion

PKG-02A/02B/02C, PKG-08B, PKG-09C, and PKG-12A already provide broad per-operation, differential, event, sparse-state, observer, and selected rollback coverage. The material uncovered interaction selected for PKG-13B is a single transaction that (1) changes row and column dimensions on one Worksheet, (2) repeatedly changes one existing formula-bearing cell through value, formula, and style operations on another Worksheet, (3) allocates a previously absent cell, then (4) fails after that allocation. The same fault matrix passed independently under Journal and Snapshot. D2-11 remains globally unresolved.
