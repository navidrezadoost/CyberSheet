## Shared transaction closure boundaries

The Workbook transaction resolves and validates every target before applying writes, canonicalizes styles before Worksheet mutation, begins per-sheet Journal or Snapshot capture and event batches, applies staged operations, settles Worksheet batches, commits Journals, marks the commit point, releases displaced style references, then publishes buffered events. Pre-commit failure restores state and drops unpublished batches; restoration or cleanup failure is represented as `recovery-required`. After the commit point observer errors are reported and isolated; they do not revert committed state.

The PKG-14B direct test adds three closure cuts that were not explicit in prior per-operation package evidence: for each operation, inject before its first apply under Journal and Snapshot; for each operation, allow that operation to apply and inject before operation two under both strategies, then compare exact Worksheet snapshot, no events, and healthy status; and dispose the Workbook from a committed value observer while a later dimension notification remains queued, checking committed state is retained and later publication is suppressed. All 30 executions passed (7 operations × 2 strategies × 2 pre-commit cuts, plus 2 publication-disposal cases). Raw output: `CS-002D4-R1-PKG-14D-focused-verified-jest-output.txt`.

These tests and the earlier packages establish only the defined seven-operation Workbook slice. They do not establish every mutation family, external persistence behavior, Workbook undo history, renderer paint completion, Application forwarding, or Workbook-owned Pivot lifecycle. Operation-specific evidence does not promote global D2-11.
